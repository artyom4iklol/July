# July

Локальный веб-журнал для репетитора. В карточке ученика хранятся профиль, уровень, цели, заметки и история занятий.

## Запуск

Нужен Python 3.10 или новее. Выполните команды в папке репозитория.

```bash
python -m venv .venv
```

Активируйте окружение командой `source .venv/bin/activate` на macOS/Linux или `.venv\Scripts\Activate.ps1` в Windows PowerShell. Затем выполните:

```bash
python -m pip install -r requirements.txt
python -m flask --app app run
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000).

## Работа с журналом

1. Добавьте ученика и заполните его уровень, цели и заметки.
2. В карточке ученика посмотрите предыдущий результат и запишите анализ для нового занятия.
3. Составьте план урока и вопросы для анкеты.
4. После урока внесите заметки и отметьте занятие проведённым.
5. Запишите ответы, итог и следующий шаг. Итог и следующий шаг появятся рядом с формой анализа следующего занятия.

## Хранение данных

SQLite создаёт файл `instance/july.sqlite3` при первом запуске. Для резервной копии остановите приложение и скопируйте этот файл. В GitHub хранится код и схема базы. Приложение рассчитано на одного преподавателя и локальный запуск на 127.0.0.1. Для общего доступа потребуется отдельное развёртывание с аутентификацией.
